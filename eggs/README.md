# Eggs

`egg-pterodactyl-neo-forge.json` is copied unchanged from
[pelican-eggs/minecraft](https://github.com/pelican-eggs/minecraft/tree/main/java/neoforge)
(MIT license, egg by glorantv). It's pinned here so installs don't change when upstream does.

To update it, download the latest `egg-pterodactyl-neo-forge.json` from that folder over this file.
Existing servers keep the old egg until you re-import it in the panel (Admin > Nests > Minecraft > NeoForge).
